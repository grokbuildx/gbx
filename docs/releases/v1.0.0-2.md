## 桌面联动运行模式、WebUI 布局修复与 Codex 压缩加固

本版本为 `gbx codex` 与 `gbx serve` 引入一致的「随客户端生命周期运行（`run`）」体验，修复 `gbx serve` 页面堆叠重复渲染问题，并彻底解决 Codex 压缩在仅流式 Chat 上游（如 WorkBuddy）及其他非原生后端下的中断问题。

### `gbx codex run` 桌面联动与短参数

- **默认桌面联动模式**：`gbx codex` 与 `gbx codex run` 启动代理后立即拉起桌面客户端（优先 **ChatGPT.app**，未安装时回退 **Codex.app**；可用 `-a chatgpt|codex` 显式二选一）。客户端退出（macOS `Cmd+Q` / Windows 进程退出）后代理自动停止并恢复 `~/.codex/config.toml`。
- **温和重启交互**：目标客户端已在运行时，交互询问 `[Y/n]` 是否温和重启，或通过 `-r` / `--restart` 直接温和重启（不强杀）；保留 `gbx codex start`（后台/CLI/IDE 无界面模式）、`status`、`stop`。
- **macOS 菜单栏增强**：监听 `NSWorkspaceDidTerminateApplicationNotification` 自动感知客户端退出；新增 `Restart <App>` 菜单项；切换配置后弹窗询问是否立即温和重启并自带重启保护窗口，不再要求手动输入 CLI 命令。
- **短参数与中英帮助文档**：新增并统一支持 `-i`/`--independent`（别名 `--solo`/`--indep`）、`-s`/`--shared`、`-w`/`--with`（兼容 `--with-provider`）、`-c`/`--catalog`、`-R`/`--refresh`、`-r`/`--restart`、`-a`/`--app`、`--no-open`，完善所有子命令的中英双语 `--help`。

### `gbx serve run` 浏览器联动与后台常驻模式

- **关闭浏览器自动退出**：`gbx serve` / `gbx serve run` 默认启动本地服务并打开浏览器；认证页面通过轻量的 `GET /api/presence` SSE 连接上报存活状态，所有标签页关闭并在 4 秒刷新宽限期后自动优雅停机退出（`Cmd+R`/`F5` 刷新不会误退；`--no-open` / `--socket` / `--auto-exit=false` 保持前台不自动退出）。
- **后台常驻与生命周期管理**：新增 `gbx serve start`（后台独立守护进程，关闭浏览器不退出，重复启动自动平滑替换旧实例）、`gbx serve status`（显示模式、PID、地址、项目数与当前已连接标签页数）与 `gbx serve stop`（通过 `127.0.0.1:0` 独立鉴权控制面优雅停机并自动清理失效状态）。
- **状态隔离与安全**：生命周期状态与日志存放在 `~/.gbx/serve/`（与 `sessions/` 隔离），`state.json` 以 `0600` 原子写入且不落盘 WebUI API token；短参数补全 `-o`/`--open`、`-w`/`--workspace`、`-m`/`--model`。

### WebUI 页面布局修复

- **修复同级重复 React `key` 导致的页面堆叠**：`App.tsx` 中 `<Thread>` 与 `<Composer>` 在新建会话时曾共用 `"new"` key，导致每次重渲染泄漏重复的 `<Thread>` 滚动容器；现已分别为其加上 `thread:` / `composer:` 前缀，并同步修复 `ProjectsPage.tsx` 中 `<DefaultsCard>` 与 `<MemoryEditor>` 的同类重复 key 及 `index.css` 中 `@import` 顺序问题。

### Codex 压缩（Compaction）与仅流式上游修复

- **修复 WorkBuddy 等仅流式 Chat 上游压缩中断**：WorkBuddy `/v2/chat/completions` 固定以流式上游调用（`streamOnly = true`），不再发送被拒绝的非流式请求（HTTP 400 `code: 11101`）；其余通用 OpenAI Chat 兼容网关在遇到 HTTP 400/422/501 拒绝非流式时自动升级为 `stream: true` 重试并按模型缓存，同时在本地将 SSE 拼装回标准 Responses JSON。
- **透传 `/v1/responses/compact` 清洗与兜底**：剥离 `/responses/compact` 禁止的回合级参数（`stream`、`store`、`tools`、`reasoning`、`max_output_tokens`、`prompt_cache_key` 等），将本地 `gbx1:` 摘要还原为普通对话文本；上游不支持 `/responses/compact` 或触发上下文溢出时自动回退到本地摘要压缩（`401`/`403`/`429` 不降级）。
- **本地与桥接压缩防溢出加固**：第三方非 Codex 原生 `openai_responses` 路由的 `compaction_trigger` 改走桥接压缩；压缩路径统一剥离 `reasoning` 参数与历史推理块、支持多轮 `gbx1:` 解码、按 UTF-8 字符边界安全截断、兼容非空 `incomplete` 摘要，并在 `context_length_exceeded` 时按梯度预算自动收紧重试。

### 升级须知

```bash
npm install -g @grokbuildx/gbx@1.0.0-2
gbx doctor
```

- Codex 守护进程协议版本升级至 `18`（新增桌面客户端监听与重启保护接口）；升级后首次执行 `gbx codex run` / `gbx codex start` 会自动平滑替换旧版守护进程。
- 现有 `~/.gbx/config.yaml`、会话历史与云同步数据完全兼容，无需迁移。
