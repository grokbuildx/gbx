## 自定义网关无 `/models` 接口兼容支持

本版本支持联通元景 MaaS 等仅开放对话推理接口、未提供 `GET /models` 模型列表接口的第三方 OpenAI 兼容网关，在 `gbx set` 终端配置面板与 `gbx serve` Web UI 中均可直接配置、验证并保存。

### 自定义网关配置与探测增强

- **`gbx set` 支持手动填写模型池**：`来源: ‹ 自定义 ›` 下的「模型列表 (Model Pool)」现支持直接输入逗号分隔的模型 ID（含 `[1m]` 上下文标记）。当未填模型先运行 `Auto Configure` 且上游 `/models` 返回 `404/403/405/501` 时，自动提示无 `/models` 目录并将焦点定位到「模型列表」，填入模型 ID 后按 `Enter` 即可完成验证与解锁保存。
- **单模型推理探测回退验证**：当网关未提供 `/models` 或返回空列表且已填写模型 ID 时，自动改用首个模型发送轻量非流式请求验证连接与 API Key（准确识别 `401/403` 及 HTTP 200 业务错误包中的鉴权失败、`404/405`、`model_not_found` 与 HTML 兜底页，放行正常响应与已通过鉴权的 `429` JSON 限流响应）。重新运行 `gbx set <name>` 编辑已有 Provider 时同样自动用已保存模型池完成验证，不再清空本地模型列表。
- **`gbx serve` Web UI 测试连接同步适配**：Web UI 区分目录拉取（打开编辑弹窗与点击「获取模型列表」仅查询 `/models`，不静默消耗推理额度）与显式点击「测试连接」（在 `/models` 不可用且已填 `Model Pool` 时自动回退验证首个模型）。
- **端点地址自动归一化**：在 `gbx set` 与 Web UI 中填写带 `/chat/completions`、`/responses` 或 `/models` 后缀的完整接口地址时，保存时自动剥离后缀归一化为基础地址（Base URL）。
