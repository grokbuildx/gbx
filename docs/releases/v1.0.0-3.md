## `gbx update` 版本查询与 npm 更新体验修复

本版本修复 `gbx update` 在 GitHub API 限流或弱网/镜像环境下检查最新版本失败，以及在版本未知时误报「npm 上还没有这个版本」的问题。

### 更新检查与安装修复

- **GitHub API 限流降级**：`api.github.com/repos/grokbuildx/gbx/releases/latest` 遇到未认证 60 次/小时限流（HTTP 403/429）或超时时，自动降级到无 API 限流的 `HEAD https://github.com/grokbuildx/gbx/releases/latest` 并从 `302 Location` 解析最新稳定 tag（仍保留对 `draft`/`prerelease` 的显式过滤）。
- **读取用户 npm 镜像源**：版本检查优先读取 `NPM_CONFIG_REGISTRY` / `npm_config_registry` 与 `~/.npmrc`（支持 `@grokbuildx:registry` 作用域配置），失败再回退 `registry.npmjs.org`。
- **并发查询与错误诊断**：GitHub Release 与 npm registry 改为并发请求，超时放宽至 10 秒并补充 `User-Agent`；当双端都无法连通时打印具体原因（例如 `GitHub: HTTP status 403; npm: ...`）便于排查。
- **区分「检查失败」与「npm 未同步」**：仅在明确查到 GitHub 新版本且 npm 确实落后时才提示「npm 上还没有这个版本」并隐藏 npm 选项；当版本检查本身失败（`unknown`）时不再误报，继续保留 `Update via npm` 默认选项，并通过 `@grokbuildx/gbx@latest` 走用户本地 npm 配置完成更新与安装校验。

### 升级须知

```bash
npm install -g @grokbuildx/gbx@1.0.0-3
gbx doctor
```

- 与 `v1.0.0-2` 完全兼容，无需额外迁移。
