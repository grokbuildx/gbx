## 本地无模型依赖 MCP 编码服务器（`gbx mcp-server`）

本版本新增 `gbx mcp-server` 子命令，支持在不配置任何大模型 API Key 或 OAuth 订阅账号的情况下，通过标准 MCP `stdio`（JSON-RPC 2.0）将本地工作区检索、代码精修、安全 Git、隔离 Git Worktree 及受控测试执行能力暴露给外部 AI 宿主（如 macOS Gemini App、Claude Desktop、Gemini CLI 等）。

### 核心特性

- **零模型配置与多源工作区发现**：独立于 `~/.gbx/config.yaml` 启动，严格保持 `stdout` 仅输出 JSON-RPC 帧并将实时调用进度输出至 `stderr`（兼容宿主「服务器日志」面板）。支持合并 `--workspace`、`--workspace-root`（自动展开直接子仓库与二级分组目录下的独立 Git 子仓库）、环境变量 `GBX_MCP_WORKSPACES` / `GBX_MCP_WORKSPACE_ROOTS`、`~/.gbx/mcp.json`（支持 `--save` 预存或宿主调用 `workspace_add` 动态注册）以及客户端 `roots/list`。
- **安全边界与防冲突编辑**：复用路径防软链逃逸检查与大小写无关 `.git` 路径拦截；`read_file` / `edit_file` / `write_file` 支持按行读取、多文件批量读写与 SHA-256 `expected_hash` 乐观锁冲突检测。
- **隔离 Git Worktree 与受控命令执行**：提供纯 `argv` 加固的 `git_status` / `git_diff` / `git_log` / `git_commit`、`worktree_create` / `worktree_list` / `worktree_merge` / `worktree_remove` 隔离分支开发流，以及带进程组超时回收与 macOS 开发工具链 `PATH` 自动补全的 `run_command`（可通过 `--no-exec` 禁用，通过 `--lock-workspaces` 锁定目录）。
- **单次授权批处理流水线（`run_batch` / `--batch-only`）**：支持在一次 MCP 调用中串联最多 25 步操作并在单测失败时自动熔断停止后续步骤；针对强制逐次弹窗确认的桌面客户端提供 `--batch-only` 模式，将多步检索或“改代码 → 跑测试 → 看 Diff”收敛为单次确认。

```bash
npm install -g @grokbuildx/gbx@1.0.0-5
gbx version
```

- 与 `v1.0.0-4` 完全向后兼容，原有 `gbx mcp ...` 仍继续透传给 Grok Build，现有配置无需额外迁移。
